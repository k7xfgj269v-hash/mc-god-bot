# 存档神权操作手册

让 Claude 成为本存档的管理神:监控一切、改一切、回档一切。核心是 **RCON 指令通道**(不用再手动敲命令)。

## 一、通道状态

| 项目 | 状态 |
|---|---|
| server.properties | `enable-rcon=true` 已写入(世界:新的世界) |
| 生效条件 | **重启游戏重进世界后激活**(改配置时读取) |
| 密码 | 自动从 server.properties 读取,无临时文件依赖 |
| 通道脚本 | `~/Documents/Projects/mc-lzmx/mc-rcon.py` |
| 监视脚本 | `~/Documents/Projects/mc-lzmx/mc-watch.py` |

## 二、通道用法(让 Claude 用,或自己终端用)

```bash
# 三态自检(配置/游戏/连通,带修复提示)
python3 ~/Documents/Projects/mc-lzmx/mc-rcon.py --check

# 发任意游戏指令
python3 ~/Documents/Projects/mc-lzmx/mc-rcon.py "give ludwigxu minecraft:diamond 64"
python3 ~/Documents/Projects/mc-lzmx/mc-rcon.py "attribute ludwigxu minecraft:generic.max_health base set 1000000"

# 等游戏重启期间自动重试
python3 ~/Documents/Projects/mc-lzmx/mc-rcon.py --retry 10 "list"

# 批量(从文件/管道逐行)
echo "time set day" | python3 ~/Documents/Projects/mc-lzmx/mc-rcon.py -
```

## 三、监视器(死亡自动补血 + 崩溃检测)

```bash
# 默认:ludwigxu 死亡后 3 秒自动把最大血量补回 1000000
python3 ~/Documents/Projects/mc-lzmx/mc-watch.py &

# 加监控玩家并设血量(--hp 跟随最近的 --player)
python3 ~/Documents/Projects/mc-lzmx/mc-watch.py --player 朋友名 --hp 2000 &

# 只检测崩溃不补血
python3 ~/Documents/Projects/mc-lzmx/mc-watch.py --no-hp &
```

特性:日志轮转自动跟随、补血失败重试 3 次、中文玩家名支持、崩溃/异常关键词 10 种。

## 四、常用神级指令速查

**属性(最大血量、移速、攻击力)**
```
attribute <玩家> minecraft:generic.max_health base set <值>
attribute <玩家> minecraft:generic.movement_speed base set 0.3
attribute <玩家> minecraft:generic.attack_damage base set 20
```

**物品 / 效果**
```
give <玩家> minecraft:diamond 64
give <玩家> touhou_little_maid:maid_model_coupon 1 6    # 女仆模型券
effect give <玩家> minecraft:resistance 999999 4 true    # 无敌(隐藏粒子)
```

**世界管理**
```
time set day / night
weather clear / rain
difficulty peaceful / easy / normal / hard
gamerule keepInventory true    # 死亡不掉落
gamerule doDaylightCycle false
```

**实体与事件**
```
summon touhou_little_maid:entity.passive.maid ~ ~1 ~    # 召唤女仆
tp @e[type=!minecraft:player,distance=..30] 0 -60 0      # 清附近实体
kill @e[type=minecraft:zombie,distance=..50]
```

**管理**
```
list                                        # 在线玩家
kick <玩家> <理由>
ban <玩家> <理由>
op <玩家> / deop <玩家>
```

## 五、神级能力的边界

- **改配置(kubejs/各 mod config)**:文件级,改完 `/kubejs reload server_scripts` 或重启生效,以房主为准朋友自动同步
- **回档**:世界已装 ftbbackups2 自动备份,必要时可从备份恢复(需重启游戏)
- **改存档文件**:玩家离线时可直接改 NBT(需另行搭建 nbtlib 工具链,未部署)
