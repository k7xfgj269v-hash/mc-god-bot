# 龙之冒险:新征程 v2.4 联机手册(2026-08-15)

## 一、当前架构(一句话)

你在游戏里开房(集成服务器)→ 本机 frpc 穿透 → 香港服务器(<FRP_HOST>:11010)→ 朋友填 `<FRP_HOST>:11010` 直连。

```
朋友(Windows/PCL2 整合包) ──▶ <FRP_HOST>:11010(香港frps) ──▶ frpc(你Mac) ──▶ 你的游戏(局域网 51620)
```

## 二、下次启动步骤(照做即可)

### 第 1 步:启动游戏客户端

```bash
bash ~/Documents/Projects/mc-lzmx/fix-lzmx-client.sh
```

- 游戏目录:`~/Library/Application Support/minecraft`(版本 1.20.1-forge-47.3.22,整合包 275 mods 已装好)
- 启动要点:脚本已内置修复(完整客户端 classpath + `-XstartOnFirstThread` + 禁用早期窗口),直接跑就行
- 加载约 1 分钟,主菜单出现即可

### 第 2 步:进存档开房

1. 主菜单 → 单人游戏 → 进存档(或新开)
2. Esc → 「对局域网开放」
3. **把「在线模式」关掉**(装了 LAN Properties mod 才有这个开关,必须关,否则离线朋友进不来)
4. 端口已固定为 **51620**(LAN Properties 固定,重启不变)

### 第 3 步:确认 frpc 在跑(端口固定后基本不用动)

```bash
pgrep -f "frpc -c"            # 有输出=在跑
# 如果端口有变(极少),改 localPort 并重启:
sed -i '' 's/localPort = 51620/localPort = <实际端口>/' ~/Documents/Projects/mc-lzmx/frpc-lzmx.toml
pkill -f "frpc -c ~/Documents/Projects/mc-lzmx/frpc-lzmx"; sleep 1
nohup frpc -c ~/Documents/Projects/mc-lzmx/frpc-lzmx.toml > /tmp/frpc-lzmx.log 2>&1 &
```

(也可以让我代劳)

### 第 4 步:告诉朋友连接

- 地址:`<FRP_HOST>`,端口 `11010`(固定不变)
- 备选:IPv6 直连 `[<IPv6>]:51620`(仅朋友端有 IPv6 时)
- 朋友条件:PCL2 导入整合包,1.20.1 + Forge 47.3.22,离线模式进

### 注意事项

- 游戏必须一直开着,你退出游戏 = 朋友掉线(当前是开房模式,不是专用服务端)
- 端口固定 51620 后,fprc 一般不用再动
- 如果朋友连不上:先查你游戏还开着、在线模式是否已关、frpc 是否在跑(`pgrep frpc`)、隧道是否通(`nc -zvw 5 <FRP_HOST> 11010`)

## 三、常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 朋友连不上 | 在线模式没关 | 重新开房,关在线模式 |
| 游戏卡顿 | 内存压力(浏览器/QQ 占内存) | 关掉大程序;多人时北京 3Mbps 带宽瓶颈 |
| 局域网开放报错 | 无 | 端口变了重改 frpc |
| PCL.Mac 打不开版本 | 不要用 PCL.Mac 导入 | 直接用 fix-lzmx-client.sh 启动 |

## 五、已踩过的坑(以后别再踩)

1. **PCL.Mac 无法导入整合包**:开发版导入功能未实现(报"版本信息错误"),下载器还有 move 撞名 bug(卡在资源下载)→ 最终手动装版本 + 脚本启动
2. **lwjgl MemoryUtil 崩溃**:根因是启动参数的 legacyClassPath 用了服务端版(没有 lwjgl 等客户端库)→ 用 python 从版本 json 重算完整 classpath
3. **黑屏卡死**:fmlearlydisplay 早期窗口线程异常导致死锁 → 加 `-Dfml.earlyprogresswindow=false`
4. **离线朋友被踢**:局域网开放默认在线验证 → 装 LAN Properties mod 关在线模式
5. **卡顿**:双 Java 进程 8G 堆超 16G 内存 → 改单进程开房模式;多人时北京出向 3Mbps 带宽是瓶颈
6. **端口转发未完成**:小米路由器 API 参数未查清(2026-08-14 待办),有公网 IPv4(<公网IP> 待确认)和公网 IPv6,后续可做直连绕开北京瓶颈
